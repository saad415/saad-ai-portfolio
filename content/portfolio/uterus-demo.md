The Uterus Demo is an interactive project page showing model output for uterine anatomical landmark detection in pelvic MRI.

It connects to Saad's uterine landmark thesis work and demonstrates how trained model predictions can be surfaced in a browser-based viewer for inspection.

The demo supports the broader portfolio story: medical imaging research can be turned into interactive tools that clinicians, researchers, and ML teams can inspect.
