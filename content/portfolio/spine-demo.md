The Spine Landmark Demo is an interactive AI demo for sacral spine landmark detection from NIfTI MRI volumes.

Visitors can select anonymized sample cases, load MRI volumes, and visualize real model predictions from a trained 3D U-Net.

The demo shows sagittal, coronal, and axial volume viewing and predicted landmarks such as L5 and S1-S5 with voxel coordinates.

It demonstrates how model outputs can be surfaced in an interactive browser viewer rather than remaining only in notebooks or offline scripts.
